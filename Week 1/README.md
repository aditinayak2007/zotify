## Overview

Week 1 laid the theoretical foundations and design analysis for Inter-Process Communication (IPC) in modern Operating Systems. The team researched, documented, and compared foundational IPC mechanisms:
1. **Shared Memory:** High-speed data exchange via mapped memory regions shared between address spaces.
2. **Pipes & FIFOs:** Kernel-managed unidirectional and bidirectional data streams with synchronization and blocking flow control.
3. **Message Passing & Synchronization:** Message queues, semaphores, and signals.
